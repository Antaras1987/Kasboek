# Kasboek Kasboek APP voor Windows en android voor gebruik met Nederlandse banken. Ondersteund CSV import en herkent automatisch inkomsten, uitgaves en vaste lasten. Basislasten worden apart van bijv. boodschappen, horeca uitgaves gezet. betaalrekening saldo automatisch herkent, spaarrekening handmatig invullen. Tijdens start van app update een JSON bestand voor betere herkenning van bijv. energie leveranciers maar ook inkomen en toeslagen. Alle gegevens worden lokaal opgeslagen of bij android SQlite database. # # # # Robert Schreutelkamp.
